# Frame de aparelho

`iphone-frame.png` é o gabarito de iPhone X / XS / 11 Pro (Space Gray) do projeto
**[PommePlate](https://github.com/ephread/PommePlate)**, distribuído sob
**CC0 1.0** (domínio público) — cópia da licença em `LICENSE-PommePlate.txt`.

Usado por [`scripts/generate-device-mockups.mjs`](../../../scripts/generate-device-mockups.mjs)
para encaixar as telas do app dentro do aparelho.

| Medida | Valor |
|---|---|
| Imagem | 1296 × 2592 |
| Área da tela | x 46 · y 47 · 1125 × 2436 |
| Proporção da tela | 0,4618 (a mesma das telas do Claquete) |

As coordenadas vieram da versão SVG do mesmo gabarito, medindo a caixa do
elemento da tela — não são estimativas.
