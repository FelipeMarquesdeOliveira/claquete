# Evidências

Prints e vídeos curtos que comprovam o funcionamento de cada entrega, conforme
pedido nas observações finais do enunciado.

| Checkpoint | Evidência esperada |
|---|---|
| CP4 | Print do app rodando com a tela de abertura da marca |
| CP5 | Vídeo curto navegando pelo protótipo no emulador ou no navegador |
| CP6 | Print do APK instalado e do app funcionando no celular |

Para gerar o print do CP4, rode `npm run web` na raiz do projeto e capture a
tela em `http://localhost:8081`.
